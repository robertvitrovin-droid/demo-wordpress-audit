# Технічний аудит WordPress-сайту з PDF-звітом (демо-проєкт)

**Демо-проєкт для портфоліо.** Аудит виконано на власному локальному стенді з вигаданим сайтом пекарні, куди навмисно внесено типові проблеми. Не робота для клієнта.

**Задача.** Власник WordPress-сайту хоче зрозуміти, чому сайт повільний, чи він у безпеці і що виправити насамперед, у вигляді зрозумілого звіту, а не набору технічних термінів.

**Рішення.**
- Неінвазивна перевірка: тільки звичайні запити до сайту, без сканування вразливостей і підбору паролів.
- Продуктивність: Lighthouse (мобільний профіль), метрики LCP / TBT / CLS, пошук важких зображень.
- Безпека: HTTPS, заголовки безпеки, виведення PHP-помилок, XML-RPC, перелік користувачів через REST API, логін «admin», службові файли.
- Плагіни й теми: інвентаризація версій через WP-CLI, застарілі й неактивні компоненти.
- SEO: description, H1, canonical, sitemap, Open Graph. Доступність: alt, контраст, тексти посилань.
- PDF-звіт: резюме для власника, докази по кожній проблемі, конкретне виправлення і план робіт за пріоритетом з оцінкою часу.

**Стек.** Python (requests, BeautifulSoup), WP-CLI, Lighthouse, WeasyPrint, PHP + SQLite для стенду.

**Результат.** 7-сторінковий PDF-звіт: 22 проблеми (6 високого, 8 середнього, 8 низького пріоритету), Lighthouse mobile 73 / 90 / 89 / 75, з таблицею плагінів і планом виправлень. Скрипти повторно використовуються для аудиту реального сайту за дозволом власника.

**Ціна від:** 1 500 грн за аудит · виправлення за окремою оцінкою · термін від 1 дня
